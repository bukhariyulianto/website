# 📖 Deskripsi

**Website, AI & Transformasi Digital Pendidikan Islam** adalah modul pembelajaran untuk mahasiswa semester 7 Program Studi Tarbiyah yang membahas bagaimana teknologi website berkembang menjadi infrastruktur peradaban digital.

Materi ini tidak hanya mengajarkan cara membuat website, tetapi membangun **cara berpikir digital (Digital Mindset)**:

> "Website bukan sekadar halaman internet, tetapi media ilmu, komunikasi, inovasi, dan perubahan sosial."

Mahasiswa diarahkan menjadi:

- Digital Educator
- Content Creator
- Web Innovator
- Islamic Technology Thinker
- Problem Solver
